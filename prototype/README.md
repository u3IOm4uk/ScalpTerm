# ScalpTerm · Дизайн 01

Локальний інтерактивний дизайн-прототип. Це не desktop-продукт і не вибір майбутнього стеку.

Відкрити `index.html` у браузері або запустити `node serve.cjs` у цій папці та перейти на http://127.0.0.1:8765.

Усі ціни, свічки, обсяги та угоди умовні й статичні. Мережевого підключення до Binance немає, торгові дії відсутні.

Можливості:

- Чотири графіки й вісім незалежних DOM у стартовому шаблоні.
- Додавання й закриття модулів; стикування за заголовок до краю цільового модуля. Перенесення в центр міняє два модулі місцями.
- Зміна розмірів перетягуванням спільної межі. Модулі не перекриваються.
- Ctrl + клік для вибору кількох модулів одного суміжного блоку; рівномірний розподіл поруч або вертикально. Окремо — однакова ширина чотирьох груп і спільна висота графіків.
- Скасування зміни компонування кнопкою або Ctrl + Z; фіксація розкладки.
- Підсвічування області вставлення при переміщенні.
- Перемикання ринку графіка та демонстраційного таймфрейму.
- Прокручування DOM коліщатком та повернення кнопкою «До ринку».
- Розгортання окремого модуля, Esc для повернення.
- Налаштування щільності й цифр; локальне збереження в браузері.

Межі: групи A–D позначають інструмент; механізм зв’язування/зміни символів не реалізований. Вирівнювання застосовується одразу й скасовується; попередній контур доступний для стикування. Агрегація, потік угод, реальні графіки, заявка/позиція та перенос між моніторами не входять у цей макет. Дизайн ще не затверджений.
