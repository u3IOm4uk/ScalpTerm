# Правила роботи над ScalpTerm

- Виконуй запити користувача поступово. Після окремої зміни покажи результат і врахуй погодження або зауваження користувача перед наступним залежним кроком.
- Погодження самої зміни не є командою на публікацію чи злиття. Публікуй на GitHub і зливай гілки лише після окремої явної команди користувача.
- Не проводь перевірок за власною ініціативою: не запускай тести, збірку, лінтери, `git diff --check` та візуальну перевірку в браузері. Користувач перевіряє результат сам і за потреби окремо просить тебе допомогти з перевіркою.
- Якщо вимога незрозуміла або інформації недостатньо, постав конкретне запитання до виконання залежної роботи.
- Якщо конкретна навичка може допомогти, спочатку назви її й поясни практичну користь простою мовою. Запропонуй підключення користувачу; додаткову навичку підключай лише після його погодження.
